## projects

### LiveStyleSync
Browser-based runtime styling system.

Click any element → edit styles → changes are written back to source files via WebSocket + Vite/Next HMR.

Core ideas:
- DOM / CSSOM inspection
- live source patching (not DevTools simulation)
- SCSS / CSS Modules / Vue scoped styles support
- overlay → websocket → file patch → HMR loop
- framework-agnostic plugin architecture

https://github.com/Artyx71/livestylesync

### ByteDojo
Terminal-first developer training environment.

A browser-based runtime sandbox for practicing real workflows:
git recovery, shell navigation, vim motions, and incident-style debugging scenarios.

Core ideas:
- terminal-first UX (xterm.js based runtime)
- scenario-driven state machine engine
- fake filesystem + command runtime
- focus on real workflows, not quizzes

https://github.com/Artyx71/ByteDojo
